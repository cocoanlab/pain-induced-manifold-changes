# Data and code for Kohoutová, Kim et al. "Capturing Pain-induced Changes in Visual Processing Through Manifold Geometry"

This repository includes codes and data necessary to reproduce main results of **heat level and image category classification, representational similarity analysis and manifold geometry**, as well as masks of the **visual regions of interest**.

The manifold geometry analysis in this work was primarily built on top of [GLUE](https://www.biorxiv.org/content/biorxiv/early/2025/03/31/2024.02.26.582157.full.pdf).
